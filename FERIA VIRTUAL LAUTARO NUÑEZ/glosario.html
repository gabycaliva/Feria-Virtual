Glosario técnico

Conceptos trabajados en clase, explicados de forma sencilla y ordenados alfabéticamente. El glosario se podrá ampliar durante el año.

Inicio Contacto
Alert()
Función de JavaScript que muestra un mensaje en una ventana emergente del navegador.
Algoritmo
Conjunto de pasos ordenados que se siguen para resolver un problema.
Archivo
Elemento digital donde se guardan datos, como documentos, imágenes, videos o música.
Archivo .bat
Archivo que contiene comandos que se ejecutan en la consola de Windows.
Bloque
Instrucción gráfica de Scratch que representa una acción dentro de un programa.
Bucle
Estructura de programación que repite una o más acciones, según una condición o cantidad de repeticiones.
Carpeta
Espacio de la computadora que sirve para guardar y organizar archivos y otras carpetas.
Clonar (Clone)
Crear en la computadora una copia local de un repositorio.
CMD
Consola de Windows que permite interactuar con la computadora mediante comandos escritos.
Commit
Registro de un conjunto de cambios en un proyecto, normalmente acompañado de un mensaje descriptivo.
Comando
Instrucción escrita que se envía a la consola para que la computadora realice una acción.
Condicional
Estructura que permite elegir qué acciones realizar según se cumpla o no una condición.
Console.log()
Función de JavaScript que muestra mensajes o resultados en la consola para ayudar a revisar el programa.
Control de versiones
Sistema que registra los cambios de un proyecto y permite consultar o recuperar versiones anteriores.
Copy
Comando que se utiliza para copiar archivos a otra ubicación.
CSS
Lenguaje que define el diseño y la apariencia de una página web, como sus colores, tipografías y espacios.
document
Objeto de JavaScript que representa el contenido de una página y permite acceder a sus elementos.
Echo
Comando que muestra un mensaje o texto en la consola.
else
Parte de una estructura condicional que indica qué hacer cuando no se cumple la condición del if.
Etiquetas
Marcas escritas entre los signos < y > que identifican elementos HTML y organizan el contenido.
Evento
Acción que ocurre en una página, como hacer clic o escribir, y que puede provocar una respuesta.
Extensión
Parte final del nombre de un archivo que ayuda a identificar su tipo, por ejemplo .html.
For
Estructura de repetición que ejecuta instrucciones varias veces, según las condiciones indicadas.
Función
Bloque de código que realiza una tarea y puede ejecutarse cada vez que se lo necesita.
getElementById()
Método de JavaScript que busca en la página el elemento que tiene un identificador determinado.
Git
Sistema de control de versiones que guarda el historial de cambios de un proyecto.
Git Add
Comando que prepara los cambios seleccionados para incluirlos en un commit.
GitHub
Plataforma en línea para guardar repositorios y compartir o desarrollar proyectos de forma colaborativa.
Git Init
Comando que inicia un repositorio Git en una carpeta.
Git Status
Comando que informa el estado del repositorio y de los cambios realizados.
Google Drive
Servicio en la nube para guardar archivos en internet y acceder a ellos desde distintos dispositivos.
HTML
Lenguaje de marcado que se utiliza para organizar la estructura y el contenido de una página web.
IDE
Programa que reúne herramientas para escribir, editar y probar código, y puede ayudar a detectar errores.
If
Estructura condicional que permite ejecutar instrucciones cuando se cumple una condición.
JavaScript
Lenguaje de programación que permite agregar comportamiento e interactividad a las páginas web.
Merge
Unir los cambios de una rama con otra rama de un proyecto.
Math.random()
Método de JavaScript que genera un número seudoaleatorio mayor o igual que 0 y menor que 1.
Mkdir
Comando que crea una carpeta nueva desde la consola.
Prompt()
Función de JavaScript que muestra una ventana y permite que el usuario escriba un dato o respuesta.
PSeInt
Programa educativo para aprender algoritmos escribiendo instrucciones en pseudocódigo.
Pull
Operación de Git que trae e integra en el repositorio local cambios disponibles en un repositorio remoto.
Push
Operación de Git que envía commits del repositorio local a un repositorio remoto.
Rama (Branch)
Versión paralela de un proyecto que permite trabajar en cambios sin modificar directamente otra rama.
Repositorio
Espacio de un proyecto que contiene sus archivos y, con Git, su historial de cambios.
Scratch
Entorno de programación visual para crear proyectos usando bloques que se encastran.
Script
Archivo con instrucciones que una computadora o programa puede ejecutar para realizar una tarea.
Trabajo colaborativo
Forma de trabajo en la que varias personas coordinan tareas y contribuyen a un mismo proyecto.
Variable
Espacio identificado por un nombre donde se almacena un valor que puede cambiar durante la ejecución.
Visual Studio Code (VS Code)
Editor de código desarrollado por Microsoft que se usa para crear y editar programas y páginas web.
