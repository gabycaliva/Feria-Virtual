En esta página encontrarás definiciones de los términos más importantes relacionados con la informática.

  • Archivo: Un archivo es un elemento digital de la computadora donde se guardan documentos, imágenes, videos, música, etc.
  • Carpeta: Una carpeta es un espacio de la computadora que sirve para guardar y organizar archivos y otras carpetas.
  • Extensión: Es el final del nombre de un archivo que permite identificar qué tipo de archivo es y con qué programa se puede abrir.
  • CMD: Es una consola de Windows que sirve para interactuar con la computadora a través de comandos escritos.
  • Comando: Es una instrucción que se le da a la computadora a través de la consola para que haga una acción específica.
  • Mkdir: Es un comando que sirve para crear nuevas carpetas dentro de la computadora.
  • Copy: Es un comando que sirve para copiar archivos a otra carpeta.
  • Echo: También es un comando que sirve para mostrar un mensaje o texto en pantalla.
  • Script: Es un conjunto de comando o instrucciones guardados en un archivo que se ejecutan de forma automática para realizar una tarea en específico.
  • Archivo .bat: Es un archivo que contiene una serie de comandos que se ejecutan automáticamente en la consola.
  • Google Drive: Es un servicio en la nube que te permite guardar información, datos y archivos en internet para poder acceder a ellos fácilmente desde cualquier lugar.
  • Trabajo Colaborativo: Es una forma de trabajo en la que varias personas participan y colaboran en un mismo proyecto de forma conjunta, compartiendo tareas, archivos, documentos, etc. Permite que varias personas trabajen en un mismo documento al mismo tiempo y de distintos lugares.
  • Scratch: Es un programa que permite crear juegos utilizando bloques de instrucciones que se encastran entre sí, sin tener que escribir el comando.
  • Bloque: Es una instrucción grafica utilizada en Scratch que sirve para realizar una acción en particular.
  • Algoritmo: Un algoritmo es un conjunto de pasos ordenadas que se siguen para resolver un problema.
  • Condicional: Es una estructura de programación que permite tomar decisiones según se cumpla una condición o no.
  • Bucle: Es una estructura de programación que permite repetir una o varias acciones muchas veces hasta que se cumpla una condición.
  • PSeInt: Es un programa que sirve para aprender programación escribiendo algoritmos de manera fácil en pseudocódigo.
  • HTML: Es un lenguaje de marcado de etiquetas que se utiliza para crear la estructura de una página web.
  • CSS: Es un lenguaje de diseño que sirve para definir el diseño, apariencia y estilo de una página.
  • JavaScript: Es un lenguaje de programación que se utiliza para que una página web sea interactiva. Permite que la página responda a las acciones del usuario.
  • Etiquetas: Son instrucciones escritas entre los símbolos <> se utilizan en HTML para indicar como debe organizarse el contenido de una página.
  • IDE: Es un programa que permite escribir, editar y probar código. También puede marcar los errores con colores y ayudarte a encontrarlos mientras programas.
  • Visual Studio Code (VS): Es un editor de código gratuito desarrollado por Microsoft que se utiliza para crear y editar programas y páginas web.
  • GitHub: Es una plataforma que sirve para guardar, compartir y trabajar en proyectos de informática de forma colaborativa.
  • Git: Es un sistema de control de versiones que guarda el historial de cambios.
  • Repositorio: Espacio donde se guarda un proyecto junto con su historial de cambios.
  • Control de versiones: Sistema que permite registrar los cambios de un proyecto y volver a versiones anteriores.
  • Commit: Registro o guardado de cambios con un mensaje descriptivo en un proyecto.
  • Rama (Branch): Versión independiente o paralela del proyecto que permite trabajar en cambios sin modificar directamente la rama principal.
  • Merge: Unir los cambios de una rama al proyecto o rama principal.
  • Push: Envía los cambios desde tu PC a GitHub.
  • Pull: trae los cambios de GitHub a la PC.
  • Clonar (Clone): Crear una copia del repositorio en la computadora.
  • Git Init: Comando que se utiliza para crear o iniciar un repositorio en Git.
  • Git Add: Comando que prepara los cambios para poder guardarlos en un Commit.
  • Git Status: Comando que muestra el estado actual de los archivos en el repositorio.
  • Alert( ): Es una función de JavaScript que muestra un mensaje en una ventana emergente del navegador.
  • Console.log( ): Es una función que muestra mensajes o resultados en la consola para ver que está haciendo el código.
  • Prompt ( ): Es una función que muestra una ventana emergente que permite al usuario ingresar un dato o una respuesta.
  • If: Es una estructura condicional que permite que el programa haga algo si se cumple una condición.
  • For: Es una estructura de repetición que permite repetir una acción varias veces, según la condición establecida.
  • Math.random: Genera un numero al azar entre 0 y un número menor que 1.
  • Función: Es un bloque de código que realiza una tarea específica y que se puede utilizar cuando sea necesario.
  • Evento: Es una acción que ocurre en una página web, como hacer clic en un botón o escribir en un campo de texto y que puede provocar una respuesta.
  • else: Permite indicar que debe hacer el programa cuando no se cumple la condición establecida en un if.
  • document: Es un objeto de JavaScript que representa el contenido de una página web y permite acceder a sus elementos como títulos, botones e imágenes.
  • getElementById (): Sirve para buscar un elemento especifico de una página HTML usando el nombre de su id.
